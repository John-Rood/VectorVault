# Supported AI Models

Vector Vault routes model IDs to OpenAI, Anthropic, xAI, or Google by catalog membership. The aliases below are the recommended VectorVault Cloud/runtime defaults as of **October 4, 2026**; explicit stable IDs are also supported. The SDK source on `main`, the published `vector-vault==7.4.9.29` package, and VectorVault Cloud share this package-owned catalog.

OpenAI GPT-6 Astra accepts text and image input and returns text through Chat Completions or Responses. Its 1,050,000-token context allows up to 922,000 input tokens and 128,000 output tokens. The public Chat Completions route supports `low`, `medium`, `high`, and `xhigh` reasoning effort, with `medium` as the documented default. Although the model page currently also names `max`, live API validation rejects both `none` and `max`; VectorVault exposes only the wire-verified set. GPT-6 Sol and Luna are public stable Chat Completions/Responses models with the same 1,050,000-token context, 922,000-token input and 128,000-token output limits. On VectorVault’s active Chat Completions path both accept `none`, `low`, `medium`, `high`, and `xhigh` reasoning (`medium` provider default); authenticated Chat Completions rejects the model-page `max` setting. Their Chat Completions function calling works only at `none` effort; reasoning plus tools requires Responses and is not implied by the chat selector. GPT-5.6 remains a stable explicit option; its `gpt-5.6` alias routes to GPT-5.6 Sol. The official `chat-latest` model has a 400,000-token context and 128,000-token output limit; the legacy `chatgpt-latest` spelling is translated locally and is never sent upstream.

GPT-6.1 Sol is a public stable option with 1,050,000-token context, 922,000 maximum input and 128,000 maximum output. Its active Chat Completions route accepts `low|medium|high|xhigh` effort, defaults to `medium`, and rejects `none`, `minimal`, and `max`. The Responses documentation advertises broader reasoning/tool support; function calling is not supported on Chat Completions. Existing OpenAI defaults remain unchanged.

Anthropic now recommends `claude-opus-5-5` as its default for most workloads. It has a 1,000,000-token context and 128,000-token output, adaptive thinking always on, `low`, `medium`, `high`, `xhigh`, and `max` effort with provider default `medium`, and supported current browser/computer-use tools. The local `claude-latest` alias now resolves to Opus 5.5; explicit Opus 5 remains accepted for existing workloads. Claude Fable 5.1 remains the demanding-reasoning/long-horizon option with all five effort levels and `high` provider default. Anthropic's Models API reports 128,000 maximum output tokens for the current Claude 5 family and supported Claude 4.6–4.8 models; Claude 4.5 models remain capped at 64,000. Older Claude models may require a legacy computer-use tool version. Invitation-only `claude-mythos-5-1` remains excluded.

Claude Sonnet 5.5 is also a public stable option with 1,000,000-token context and 128,000 maximum output. It supports adaptive `low|medium|high|xhigh|max` effort, defaults to `high`, and rejects non-default `temperature`, `top_p`, and `top_k`. Adaptive thinking is on by default. Its optional `between_tools` mode is separate from effort and is not exposed as a generic thinking-level option. The Anthropic default and `claude-latest` remain Opus 5.5.

Gemini 3.8 Flash is GA and replaces 3.7 Flash as the Google product default and the local `gemini-latest` target. It accepts text, image, video, audio, and PDF input with a 1,048,576-token context and 65,536-token maximum output. Its thinking levels are `low`, `medium`, and `high`, with `medium` as the provider default; `minimal` is explicitly unsupported. The current GenerateContent route accepts `temperature`, `top_p`, and `top_k` alongside explicit thinking levels, so VectorVault forwards those sampling controls; `candidate_count` remains omitted. Gemini 3.7 Flash remains an explicit stable option for existing workloads. Gemini image generation uses the stable backend-only `gemini-3-pro-image` model with the Models API's 131,072-token input and 32,768-token output limits; it is not shown in text-chat selectors, and the retired `gemini-3-pro-image-preview` ID is translated locally for saved integrations.

## Compatibility IDs

The SDK's backend catalog retains older provider-accepted or redirected IDs so existing integrations and saved VectorFlow graphs continue to load. Retired Claude Sonnet 4 IDs (`claude-sonnet-4-0`, `claude-sonnet-4-20250514`), redirected Grok 3/4 aliases, and legacy Gemini shorthand `gemini-3.1-pro` are compatibility-only and are intentionally absent from current model selectors. The Gemini shorthand resolves locally to the accurately labeled preview ID `gemini-3.1-pro-preview`; that preview remains backend-only. The documented deprecated `gpt-5.3-chat-latest` snapshot remains a backend-only pass-through ID at 128k context/16,384 output. The invalid `gpt-5.3` and undocumented GPT-5.4/5.5 chat aliases are translated locally for compatibility but hidden from selectors. Shut-down Gemini 3 preview and Gemini 2.0 IDs are also excluded from the current stable list and migrated locally where a safe successor exists.

Claude Sonnet 4.5 (`claude-sonnet-4-5`) was deprecated on September 30, 2026 and is now hidden from current selectors. It remains backend-compatible for existing saved flows until the provider retirement on November 30, 2026. Records without `thinking_level` still omit the provider parameter rather than forcing a level.

xAI's official `grok-latest` alias remains preserved as the previously documented `grok-4.3` target; Vector Vault defaults new code/chat work to `grok-4.7` because xAI now recommends it for those workloads. Grok 4.3 supports `none`, `low`, `medium`, and `high` reasoning effort (provider default when omitted), text and image input, function calling, and structured outputs. xAI's model index and individual model pages agree that Grok 4.5 has a 500,000-token context and the Grok 4.20 reasoning/non-reasoning family has a 1,000,000-token context. Current xAI aliases—including `grok-4.5-latest`, `grok-build-latest`, `grok-4.3-latest`, the stable Grok 4.20 aliases, and Grok Build's `grok-code-fast*` aliases—are supported in the backend catalog and normalized locally to their documented canonical IDs. They are hidden from selectors when they would duplicate an existing stable-model option. The beta-only Grok 4.20 Multi-Agent model is not promoted into the stable selector catalog.

Use an explicit compatibility ID only while migrating an existing workload. New code should use the recommended default alias or a current stable ID from the table above.

## October 2026 additions

- **GPT-6.1 Sol**: stable 1,050,000 context/128,000 output; active Chat Completions `low|medium|high|xhigh`, `medium` default.
- **Claude Sonnet 5.5**: stable 1,000,000 context/128,000 output; adaptive `low|medium|high|xhigh|max`, `high` default.
- **Sonnet 4.5 deprecation**: removed only from current selectors; existing backend/saved-flow IDs are preserved until provider retirement.
- **Completed family audit**: `o3` and `o4-mini` (`low|medium|high|xhigh`), `gpt-5-mini`/`gpt-5-nano` and `gemini-3.1-flash-lite` (`minimal|low|medium|high`) now expose their full named reasoning sets. Gemini 3.1 Flash-Lite's documented default is `minimal`.
- **GPT-5.6 `max` retired on the active route**: the final live audit rejected `max` for every GPT-5.6 variant on Chat Completions. Saved flows that still request it clamp to `xhigh` instead of failing.
- **Unconditional sampling omission**: models on this list that reject non-default `temperature` (o-series, GPT-5.5, GPT-5.6/6 variants, GPT-5 Mini/Nano, `chat-latest`) now omit it even when no thinking level is selected.
- **Account-restricted Gemini 2.5 Flash-Lite**: Google returns HTTP 404 "no longer available to new users" for this ID on the VectorVault account (2.5 Pro and 2.5 Flash remain available). It is hidden from current selectors, preserved for saved flows, and the vendor-recommended successor is `gemini-3.5-flash-lite`.
- **Responses-only o3-pro**: not selectable for chat because Chat Completions rejects it; the explicit ID and its endpoint limitation are documented here.

## September 2026 additions

- **GPT-6 Sol and Luna**: public stable 1,050,000-context/128,000-output models; on the active Chat Completions route `none|low|medium|high|xhigh` are accepted (not `max`), with `medium` default.
- **Claude Opus 5.5**: recommended default and `claude-latest` target, 1M context/128k output; always-adaptive `low` through `max` effort, `medium` default.
- **Grok 4.7**: xAI recommended default, 500k context, image/text input; `low|medium|high|xhigh` effort, `high` default.
- **GPT-6 Astra**: public stable default snapshot; 1,050,000-token context, 922,000 maximum input, 128,000 maximum output; wire-verified `low`, `medium`, `high`, and `xhigh` reasoning effort; Chat Completions and Responses support.
- **Claude Fable 5.1**: public Claude API model with 1,000,000-token context and 128,000-token output; adaptive `low` through `max` effort; current hosted browser/computer-use support.
- **Gemini 3.8 Flash**: GA September 2, 2026; 1,048,576-token context and 65,536-token output; `low`, `medium`, and `high` thinking with `medium` default; `temperature`, `top_p`, and `top_k` are forwarded, while `minimal` thinking and `candidate_count` remain rejected.

Older stable entries remain accepted for saved-flow and API compatibility. Private/invitation-only models, including Claude Mythos 5.1, are intentionally excluded.
