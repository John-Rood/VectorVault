# Supported AI Models

Vector Vault routes model IDs to OpenAI, Anthropic, xAI, or Google by catalog membership. The aliases below are the recommended VectorVault Cloud/runtime defaults as of **November 1, 2026**; explicit stable IDs are also supported. The SDK source on `main`, the published `vector-vault==7.4.9.33` package, and VectorVault Cloud share this package-owned catalog.

OpenAI GPT-6 Astra accepts text and image input and returns text through Chat Completions or Responses. Its 1,050,000-token context allows up to 922,000 input tokens and 128,000 output tokens. The public Chat Completions route supports `low`, `medium`, `high`, and `xhigh` reasoning effort, with `medium` as the documented default. Although the model page currently also names `max`, live API validation rejects both `none` and `max`; VectorVault exposes only the wire-verified set. GPT-6 Sol and Luna are public stable Chat Completions/Responses models with the same 1,050,000-token context, 922,000-token input and 128,000-token output limits. On VectorVault’s active Chat Completions path both accept `none`, `low`, `medium`, `high`, and `xhigh` reasoning (`medium` provider default); authenticated Chat Completions rejects the model-page `max` setting. Their Chat Completions function calling works only at `none` effort; reasoning plus tools requires Responses and is not implied by the chat selector. GPT-5.6 remains a stable explicit option; its `gpt-5.6` alias routes to GPT-5.6 Sol. The official `chat-latest` model has a 400,000-token context and 128,000-token output limit; the legacy `chatgpt-latest` spelling is translated locally and is never sent upstream.

GPT-6.1 Terra (released October 26, 2026) is a public stable option for visual reasoning, computer use and writing, with the same 1,050,000-token context, 922,000 maximum input and 128,000 maximum output; it accepts text and image input. Its active Chat Completions route accepts `none|low|medium|high|xhigh` effort with `medium` as the provider default; `minimal` and the model page's Responses-only `max` are rejected. Non-default `temperature` is omitted, and function tools on Chat Completions work only at `none` effort.

GPT-6.1 Sol is a public stable option with 1,050,000-token context, 922,000 maximum input and 128,000 maximum output. Its active Chat Completions route accepts `low|medium|high|xhigh` effort, defaults to `medium`, and rejects `none`, `minimal`, and `max`. The Responses documentation advertises broader reasoning/tool support; function calling is not supported on Chat Completions. Existing OpenAI defaults remain unchanged.

Anthropic now recommends `claude-opus-5-5` as its default for most workloads. It has a 1,000,000-token context and 128,000-token output, adaptive thinking always on, `low`, `medium`, `high`, `xhigh`, and `max` effort with provider default `medium`, and supported current browser/computer-use tools. The local `claude-latest` alias now resolves to Opus 5.5; explicit Opus 5 remains accepted for existing workloads. Claude Fable 5.1 remains the demanding-reasoning/long-horizon option with all five effort levels and `high` provider default. Anthropic's Models API reports 128,000 maximum output tokens for the current Claude 5 family and supported Claude 4.6–4.8 models; Claude 4.5 models remain capped at 64,000. Older Claude models may require a legacy computer-use tool version. Invitation-only `claude-mythos-5-1` remains excluded.

Claude Sonnet 5.5 is also a public stable option with 1,000,000-token context and 128,000 maximum output. It supports adaptive `low|medium|high|xhigh|max` effort, defaults to `high`, and rejects non-default `temperature`, `top_p`, and `top_k`. Adaptive thinking is on by default. Its optional `between_tools` mode is separate from effort and is not exposed as a generic thinking-level option. The Anthropic default and `claude-latest` remain Opus 5.5.

Gemini 4 Argon (`gemini-4-argon`) is GA, released October 13. Its **1,048,576-token window is shared by input, thinking, and output**, not separate 1M input plus 1M output allowances. It accepts text, images, video, audio, and PDF, and returns text. It supports function calling, structured output, Google Search/Maps grounding, URL context, code execution, file search, and agentic video understanding; computer use remains a preview tool. Thinking is always on: `low|medium|high`, provider default `medium`; `minimal` is rejected. For Argon only, VectorVault omits ignored `temperature`, `top_p`, `top_k`, deprecated `thinking_budget`, unsupported `candidate_count`, and explicit `cached_content` (implicit caching is supported). Google recommends a 20-minute HTTP timeout for long-running requests.

Argon's default output budget is 65,536 tokens. Direct non-streaming REST requests cap each response at 32,768, streaming at 65,536; **long decode requires `google-genai>=2.30.1`** and explicit `max_output_tokens>65536`, with SDK automatic continuation and total input+thinking+output within 1,048,576. VectorVault 7.4.9.31 declares that SDK floor. Existing Gemini defaults and `gemini-latest` intentionally remain on 3.8 Flash, so omitted-model behavior and saved flows do not silently switch to a new generation. Select Argon explicitly.

Gemini 3.8 Flash is GA and replaces 3.7 Flash as the Google product default and the local `gemini-latest` target. It accepts text, image, video, audio, and PDF input with a 1,048,576-token context and 65,536-token maximum output. Its thinking levels are `low`, `medium`, and `high`, with `medium` as the provider default; `minimal` is explicitly unsupported. The current GenerateContent route accepts `temperature`, `top_p`, and `top_k` alongside explicit thinking levels, so VectorVault forwards those sampling controls; `candidate_count` remains omitted. Gemini 3.7 Flash and 3.5 Flash were deprecated by Google (requests are routed to 3.8 Flash and 3.6 Flash respectively); they are hidden from selectors and retained for saved flows. Gemini image generation uses the stable backend-only `gemini-3-pro-image` model with the Models API's 131,072-token input and 32,768-token output limits; it is not shown in text-chat selectors, and the retired `gemini-3-pro-image-preview` ID is translated locally for saved integrations.

## Compatibility IDs

OpenAI shut down `o4-mini`, `o1`, `o3-mini`, `gpt-4`, and `gpt-3.5-turbo` on **October 23, 2026**; the API now returns `model_not_found` for them. VectorVault removed `o4-mini` from current selectors and resolves every retired ID locally to OpenAI's documented substitute before calling the provider: `o4-mini` and `gpt-3.5-turbo` → `gpt-5.6-terra`; `o1`, `o3-mini`, and `gpt-4` → `gpt-5.6-sol`. The same substitution now applies to earlier shut-down IDs that still appeared in saved records (`o1-mini` → `gpt-5.6-terra`; `chatgpt-4o-latest` and `gpt-5`/`5.1`/`5.2`/`5.3-chat-latest` → `gpt-5.6-sol`). Saved flows keep running, retired IDs are never sent upstream, and saved o4-mini reasoning levels (`low|medium|high|xhigh`) remain valid on GPT-5.6 Terra. `gpt-4o-audio-preview` (shut down May 7, 2026) has no text-chat substitute because its successor `gpt-audio-1.5` requires audio input or output; it is retained only so legacy records load.

OpenAI deprecated GPT-4o and GPT-4o Mini on October 14, with shutdown scheduled for **January 14, 2027** and `gpt-6-luna` as the provider-recommended replacement. `gpt-4o` and `gpt-4o-mini` are hidden from current selectors but remain available through `/all_model_list` for saved flows before shutdown. Select a current model for new workloads.

The SDK's backend catalog retains older provider-accepted or redirected IDs so existing integrations and saved VectorFlow graphs continue to load. Retired Claude Sonnet 4 IDs (`claude-sonnet-4-0`, `claude-sonnet-4-20250514`), redirected Grok 3/4 aliases, and legacy Gemini shorthand `gemini-3.1-pro` are compatibility-only and are intentionally absent from current model selectors. The Gemini shorthand resolves locally to the accurately labeled preview ID `gemini-3.1-pro-preview`; that preview remains backend-only. The documented deprecated `gpt-5.3-chat-latest` snapshot remains a backend-only pass-through ID at 128k context/16,384 output. The invalid `gpt-5.3` and undocumented GPT-5.4/5.5 chat aliases are translated locally for compatibility but hidden from selectors. Shut-down Gemini 3 preview and Gemini 2.0 IDs are also excluded from the current stable list and migrated locally where a safe successor exists.

Claude Sonnet 4.5 (`claude-sonnet-4-5`, 200,000-token context, 64,000 output) was deprecated on September 30, 2026 and is now hidden from current selectors. It remains backend-compatible for existing saved flows until the provider retirement on November 30, 2026. Records without `thinking_level` still omit the provider parameter rather than forcing a level.

xAI's official `grok-latest` alias remains preserved as the previously documented `grok-4.3` target; Vector Vault defaults new code/chat work to `grok-4.7` because xAI now recommends it for those workloads. Grok 4.3 supports `none`, `low`, `medium`, `high`, and `xhigh` reasoning effort (provider default `low` when omitted), text and image input, function calling, and structured outputs. xAI's model index and individual model pages agree that Grok 4.5 has a 500,000-token context and the Grok 4.20 reasoning/non-reasoning family has a 1,000,000-token context. Current xAI aliases—including `grok-4.5-latest`, `grok-build-latest`, `grok-4.3-latest`, the stable Grok 4.20 aliases, and Grok Build's `grok-code-fast*` aliases—are supported in the backend catalog and normalized locally to their documented canonical IDs. They are hidden from selectors when they would duplicate an existing stable-model option. The beta-only Grok 4.20 Multi-Agent model is not promoted into the stable selector catalog.

Use an explicit compatibility ID only while migrating an existing workload. New code should use the recommended default alias or a current stable ID from the table above.

## November 1, 2026 update

- **GPT-6.1 Terra** (`gpt-6.1-terra`): new current option; 1,050,000 context, 922,000 input, 128,000 output; `none|low|medium|high|xhigh`, `medium` default (wire-verified on Chat Completions; `max` rejected).
- **OpenAI December 11 shutdowns**: OpenAI's models API now reports `shutdown_date` 2026-12-11 for the undated `o3`, `gpt-5-mini` and `gpt-5-nano` IDs (replacements `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`). - **Retired Claude IDs**: `claude-opus-4-1` (now `claude-opus-4-8`), `claude-sonnet-4-0`, `claude-sonnet-4-20250514`, `claude-3-7-sonnet-latest`, `claude-3-5-sonnet-latest` (now `claude-sonnet-5-5`) and `claude-3-5-haiku-latest` (now `claude-haiku-4-5`) return HTTP 404 from Anthropic. - **Gemini Computer Use GA** (October 30): recorded as a supported Gemini 4 Argon tool.

## October 25, 2026 update

- **OpenAI October 23 shutdowns**: `o4-mini` leaves the current selector list. `o4-mini`, `o1`, `o3-mini`, `gpt-4`, `gpt-3.5-turbo` and previously retired chat snapshots now route locally to `gpt-5.6-terra` / `gpt-5.6-sol` for saved flows (see Compatibility IDs).

VectorVault 7.4.9.32 keeps explicit sampling working on Claude models that accept it (Opus 4.5, Sonnet 4.6, Haiku 4.5, Sonnet 4.5) by sending `anthropic-version: 2023-06-01` on those requests, as Anthropic's migration guide allows. Claude models that reject sampling are unaffected.
- **Claude Sonnet 4.5** context corrected to 200,000 tokens.
- No new generally available text models from OpenAI, Anthropic, xAI or Google since October 18. Defaults, aliases and every current thinking contract were re-verified on the live APIs and are unchanged.

## October 18, 2026 update

- **Gemini 4 Argon**: GA `gemini-4-argon`, 1,048,576 shared input/thinking/output tokens; `low|medium|high`, default `medium`; no `minimal` or off mode. New selections are API-driven.
- **Long-decode SDK floor**: `google-genai>=2.30.1`. Short-answer wire tests also accepted an explicit 262,144-token budget on both the minimum SDK and current SDK, streaming and non-streaming; this was not a million-token output stress test.
- **Argon-specific sampling/caching omissions** do not change Gemini 3.8 Flash sampling behavior.
- **GPT-4o deprecations**: remove only `gpt-4o` from new selectors (Mini was already backend-only), retaining both IDs for saved flows until January 14, 2027.
- **Defaults and thinking contracts preserved** for OpenAI, Anthropic, xAI, and existing Gemini models. Fresh active-route probes still reject OpenAI `max` despite its appearance in Responses/model documentation.

## October 11, 2026 update

It rejects `none`, non-default `temperature`, and `top_p`/`top_k`; VectorVault omits all sampling fields. Supports hosted browser use, computer use (`computer_toolset_20260801`), web search/fetch and code execution.

- No changes to defaults, aliases, GPT-6 Astra, GPT-6.1 Sol, or Gemini 3.8 Flash thinking contracts.

## October 2026 additions

- **GPT-6.1 Sol**: stable 1,050,000 context/128,000 output; active Chat Completions `low|medium|high|xhigh`, `medium` default.
- **Claude Sonnet 5.5**: stable 1,000,000 context/128,000 output; adaptive `low|medium|high|xhigh|max`, `high` default.
- **Sonnet 4.5 deprecation**: removed only from current selectors; existing backend/saved-flow IDs are preserved until provider retirement.
- **Completed family audit**: `o3` and `o4-mini` (`low|medium|high|xhigh`), `gpt-5-mini`/`gpt-5-nano` and `gemini-3.1-flash-lite` (`minimal|low|medium|high`) now expose their full named reasoning sets. Gemini 3.1 Flash-Lite's documented default is `minimal`.
- **GPT-5.6 `max` retired on the active route**: the final live audit rejected `max` for every GPT-5.6 variant on Chat Completions. Saved flows that still request it clamp to `xhigh` instead of failing.
- **Unconditional sampling omission**: models on this list that reject non-default `temperature` (o-series, GPT-5.5, GPT-5.6/6 variants, GPT-5 Mini/Nano, `chat-latest`) now omit it even when no thinking level is selected.
- **Account-restricted Gemini 2.5 Flash-Lite**: Google returns HTTP 404 "no longer available to new users" for this ID on the VectorVault account (2.5 Pro and 2.5 Flash remain available). It is hidden from current selectors, preserved for saved flows, and the vendor-recommended successor is `gemini-3.5-flash-lite`.
- **Responses-only o3-pro**: not selectable for chat because Chat Completions rejects it; the explicit ID and its endpoint limitation are documented here.

## September 2026 additions

- **GPT-6 Sol and Luna**: public stable 1,050,000-context/128,000-output models; on the active Chat Completions route `none|low|medium|high|xhigh` are accepted (not `max`), with `medium` default.
- **Claude Opus 5.5**: recommended default and `claude-latest` target, 1M context/128k output; always-adaptive `low` through `max` effort, `medium` default.

- **GPT-6 Astra**: public stable default snapshot; 1,050,000-token context, 922,000 maximum input, 128,000 maximum output; wire-verified `low`, `medium`, `high`, and `xhigh` reasoning effort; Chat Completions and Responses support.
- **Claude Fable 5.1**: public Claude API model with 1,000,000-token context and 128,000-token output; adaptive `low` through `max` effort; current hosted browser/computer-use support.
